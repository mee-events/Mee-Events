# Accessibility

- Status: accepted

## 1. Targets

- Minimum contrast: body text on canvas meets WCAG AA
- Primary coral on white is for large text/UI chrome; prefer ink for long reading
- Hit targets ≥ 44×44 lp

## 2. Semantics

- Buttons and tabs expose labels
- Errors announced with text, not colour alone
- Images provide meaningful `semanticsLabel` or are marked decorative

## 3. Forms

- Labels permanently visible or correctly associated
- OTP fields support one-time-code autofill hints
- Phone fields use telephone keyboard

## 4. Motion

Honour reduced motion where the platform exposes it.
