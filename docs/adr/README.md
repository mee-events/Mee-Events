# Architecture Decision Records

ADRs capture decisions that are expensive to reverse. Accepted records are the
engineering source of truth. A later decision must supersede an earlier record;
history is never silently rewritten.

Statuses: `proposed`, `accepted`, `deprecated`, `superseded`.

Product scope is governed by the PRD suite in `../product/prd/`
(ADR 0011). ADRs remain the source of truth for engineering decisions.
